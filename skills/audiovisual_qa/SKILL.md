# Skill: Belisario Audiovisual QA

## 🔍 Criterios de Evaluación

1. **Resolución Estándar:** 1080x1920 para Shorts (9:16) y 1920x1080 para Ensayos (16:9).
2. **Streams Activos:** Ambos flujos H.264 (vídeo) y AAC (audio) presentes.
3. **Puntuación Mínima de Calidad:** 85/100 para aprobar publicación.
4. **Re-renderizado Automático:** Disparado de inmediato si la puntuación cae por debajo de 85/100.
