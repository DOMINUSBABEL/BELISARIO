# 🛡️ BELISARIO: Master Autonomous Orchestrator & Dialectical Quality Engine

> **BELISARIO** es la cúspide de orquestación autónoma de la suite de agentes **BABYLON.IA**. Actúa como el Director Supremo encendido permanentemente en bucle para supervisar, calendarizar, publicar y elevar de forma continua la calidad audiovisual y estratégica de los ecosistemas **VAREGO** (distribución social) y **KINESIO** (generación y montaje audiovisual autónomo).

## 💡 Filosofía e Integración Dialéctica

BELISARIO trasciende los gestores de contenido tradicionales. Opera como una entidad autorregulada guiada por los principios de la **Arquitectura Geist** (`geist.md`):

1. **Tesis (Ejecución de Campaña):** Supervisa y despliega bucles de publicación optimizados (3-4 publicaciones diarias espaciadas por 4 horas) para evitar la sofocación por spam en los algoritmos de recomendación (YouTube Shorts, X, TikTok).
2. **Antítesis (Inspección de Métricas & Anomalías):** Extrae la telemetría empírica a las 24h y 48h de publicación, identificando caídas en la retención del espectador, baja interacción o ganchos ineficaces.
3. **Síntesis (Auto-Refactorización & Memoria):** Dispara refactorizaciones automáticas sobre el código fuente de los repositorios **KINESIO** (`kinesio_core.py`) y **VAREGO** (`upload_youtube_dominus.js`), elevando los estándares de kinetic text, audio ducking, layouts split-screen y ganchos narrativos sin pérdida de sustancia.

## 🚀 Guía de Uso e Instalación

### Requisitos Previos
* **Python 3.11+**
* **Node.js 18+** y **Puppeteer**
* **FFmpeg** (con soporte para `libx264`, `aac` y filtro `sidechaincompress`)

### Instalación
```bash
# Clonar repositorio BELISARIO
git clone https://github.com/DOMINUSBABEL/BELISARIO.git
cd BELISARIO

# Instalar dependencias de Python
pip install -r requirements.txt

# Instalar dependencias de Node.js
npm install
```

### Ejecución del Orquestador Autónomo
```bash
# Iniciar el bucle autónomo del Director BELISARIO
python belisario_orchestrator.py --loop

# O ejecutar una auditoría de calidad inmediata
python belisario_orchestrator.py --audit --channel @dominus8735
```
